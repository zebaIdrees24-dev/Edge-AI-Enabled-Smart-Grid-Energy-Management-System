# Adaptation from IoT threat detection

| Original theme | Smart-grid EMS adaptation |
|---|---|
| IoT traffic telemetry | Meter, DER, weather, voltage, frequency, and battery telemetry |
| Edge attack detection | Edge load forecasting and grid-state anomaly detection |
| Cloud deep analysis | Higher-capacity cloud load forecast and future fleet analysis |
| Dynamic threat escalation | Uncertainty/anomaly/safety-driven cloud escalation |
| Attack response | Charge, discharge, hold, battery preservation, or protection recommendation |

The shared research question is whether adaptive placement of intelligence can preserve fast local response while selectively using cloud resources for harder cases.
